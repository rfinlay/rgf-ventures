# RadAssist Calcium-Score Pilot
## Installation Guide (Windows)

**Prepared for:** Dr. Luis Ramos
**Prepared by:** Rick Finlay, RGF Global Ventures
**Version:** Pilot 1 (standalone)

---

### What you are installing
A single file: **`RadAssist-CalciumScore.html`**. It is a self-contained tool that runs in your web browser, **fully offline**. There is no installer, no admin rights required, and nothing that touches your PACS or your system.

---

### Step 1 — Save the file
Save **`RadAssist-CalciumScore.html`** somewhere permanent, such as your **Documents** or **Desktop** folder. Do not run it straight from the email preview or a temporary Downloads location.

### Step 2 — Open it
Double-click the file. It opens in your default browser (**Chrome or Edge recommended**). If Windows asks, choose **Open** / **Keep**.

To confirm it is truly offline: you can turn off your internet connection and it still runs. Nothing uploads, ever.

### Step 3 (optional) — Make it easy to launch
Pick whichever you prefer:
- **Desktop shortcut:** right-click the file → **Show more options** → **Send to** → **Desktop (create shortcut)**.
- **Bookmark it:** with it open in your browser, press **Ctrl+D** and save it to your bookmarks bar.
- **Install it as an app (cleanest):** open the file in Chrome or Edge, then:
  - **Chrome:** ⋮ menu → **Cast, save, and share** → **Create shortcut…** → check **Open as window** → **Create**.
  - **Edge:** ⋯ menu → **Apps** → **Install this site as an app**.
  It will then appear in your **Start menu** and open in its own clean window, like any program.

### Step 4 — Verify it works
Enter this quick test: **Left Main 0, LAD 14, LCx 2, RCA 9, Age 65, Male, Hispanic**, then **Generate**.
You should see **Total Agatston score 25** and **percentile ~51**. If you do, you are all set.

---

### Privacy notes
- Everything runs on your machine. **No patient data is transmitted** — the tool makes no network calls.
- **No patient identifiers** are needed or stored (only scores plus age, sex, and ethnicity). Nothing is saved after you close it.

### To uninstall
Just delete the file (and any shortcut you made). That is the entire uninstall.

### If something looks off
- If double-clicking opens a page of code or plain text instead of the tool, right-click the file → **Open with** → **Chrome** (or your browser).
- Any snags, send them to **Rick**.

---

*RadAssist runs locally and stores nothing. This guide and the tool contain no patient health information.*
